# Layoutstudio Assets

랜딩 페이지에서 사용하는 선택 자산을 넣는 폴더입니다.

## 프로필 이미지

인스타그램 프로필 이미지를 저장한 뒤 아래 파일명으로 넣으세요.

```txt
assets/creator-profile.jpg
```

권장 규격:

- 파일 형식: JPG 또는 PNG
- 권장 크기: 512 x 512px 이상 정사각형
- 파일명: `creator-profile.jpg`

## 후원 QR 이미지

카카오페이, 토스 QR 이미지를 사용할 경우 아래 파일명으로 저장하세요.

```txt
assets/kakaopay-qr.png
assets/toss-qr.png
```

QR 이미지를 넣지 않아도 랜딩 페이지는 깨지지 않고 안내 박스만 표시됩니다.
