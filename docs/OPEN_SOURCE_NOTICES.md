# 오픈소스 라이선스 안내

Layoutstudio SPACE `v0.1.0-alpha`는 정적 웹 앱으로 동작하며, 앱 실행에 필요한 주요 오픈소스 라이브러리는 다음과 같습니다.

| 이름 | 용도 | 라이선스 | 요약 |
| --- | --- | --- | --- |
| Fabric.js | 2D 캔버스 렌더링, 가구 선택/이동, 레이어 구성 | MIT | 저작권 고지와 라이선스 고지를 유지하면 사용, 수정, 배포가 가능한 허용적 라이선스입니다. |
| Tesseract.js | 도면 이미지의 치수 후보 OCR 보조 분석 | Apache-2.0 | 고지와 라이선스 조건을 지키면 사용, 수정, 배포가 가능하며 특허 라이선스 조항을 포함합니다. |
| Lucide | 상단/패널/버튼 아이콘 표시 | ISC | 저작권 및 허가 고지를 포함하면 사용과 배포가 가능한 짧은 허용적 라이선스입니다. |

## 레퍼런스 확인 및 적용 범위

- `fabric-schematics`: 레이어 추상화와 잠긴 도면 레이어 구조를 참고했습니다.
- `fabricjs-viewport`: 줌/팬이 실제 데이터 값을 변경하지 않는 뷰 상태 관리 방식을 참고했습니다.
- `design-editor`: 선택 오브젝트 수정, 복제, 삭제, 앞/뒤 이동 액션 구성을 참고했습니다.
- `react-floorplanner`: 카탈로그 기반 가구 보관함 구조를 참고했습니다.

위 레퍼런스에서 직접 복사한 코드는 없습니다. 구조와 구현 패턴만 현재 Vanilla JavaScript/Fabric.js 코드에 맞게 재구현했습니다.

GPL 계열 또는 라이선스가 불명확한 코드는 Layoutstudio에 직접 복사하지 않았습니다.
