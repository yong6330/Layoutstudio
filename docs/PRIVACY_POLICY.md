# 개인정보처리방침

Layoutstudio SPACE는 현재 `v0.1.0-alpha` 단계의 ONESTUDIO 알파입니다.

현재 버전은 별도의 운영 서버 데이터베이스에 워크스페이스 데이터를 저장하지 않으며, 사용자의 브라우저 LocalStorage와 사용자가 직접 내보내는 JSON 파일을 중심으로 동작합니다.

## 저장될 수 있는 정보

- 로컬 계정 식별용 이메일
- 워크스페이스명
- 도면명
- 도면 이미지 데이터
- 도면 기준 영역
- 실측 크기
- 가구 보관함 목록
- 배치된 가구의 좌표, 회전값, 색상, 메모
- 방/영역 구조 레이어 데이터
- JSON 내보내기 데이터

## 저장 위치

정보는 현재 브라우저 LocalStorage와 사용자가 직접 저장한 JSON 파일에 있습니다. 운영 서버로 자동 전송하지 않습니다.

## 삭제 방법

앱의 워크스페이스 삭제 버튼으로 LocalStorage에 저장된 항목을 삭제할 수 있습니다. 브라우저 사이트 데이터를 삭제하면 저장된 워크스페이스도 삭제될 수 있습니다.

## 제3자 제공

현재 앱은 워크스페이스 데이터를 제3자에게 제공하지 않습니다. 다만 CDN으로 Fabric.js, Tesseract.js, Lucide, 웹폰트를 불러오는 과정에서 CDN 제공자에게 일반적인 접속 로그가 남을 수 있습니다.

## 향후 갱신

실제 계정, 데이터베이스, 이미지 저장소가 도입되면 저장 위치, 접근 권한, 보관 기간에 맞춰 정책을 갱신해야 합니다.
