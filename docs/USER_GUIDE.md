# 이용 안내

Layoutstudio SPACE는 도면 이미지를 기준 자료로 사용해 실제 크기의 워크스페이스를 만들고, 가구 보관함의 원본 가구를 도면 위에 배치해 보는 알파 버전 웹 앱입니다.

## 워크스페이스와 도면

- 워크스페이스는 하나의 저장 단위이자 공간 묶음입니다.
- 도면은 워크스페이스 안에 들어가는 floorplan입니다.
- 현재 화면은 하나의 기본 도면 중심으로 동작하지만, 저장 구조는 향후 여러 도면을 담을 수 있도록 준비되어 있습니다.

## 기본 흐름

1. `새 워크스페이스 만들기`에서 도면 이미지를 업로드합니다.
2. 워크스페이스명과 도면명을 입력합니다.
3. OCR 치수 후보는 추천값으로만 확인하고, 실제 배치 영역의 가로/세로 mm를 직접 확정합니다.
4. 도면 기준 영역을 파란 박스로 드래그하거나 핸들로 조정합니다. 여백, 치수선, 라벨, 발코니처럼 가구 배치와 무관한 영역은 제외합니다.
5. 초기 가구 보관함 단계에서 프리셋을 선택/수정하거나 직접 가구를 추가합니다.
6. 가구 보관함에서 배치 버튼 또는 드래그로 가구를 도면 위에 올립니다.
7. 우측 선택 패널에서 이름, 종류, 크기, X/Y 실측 좌표, 회전, 색상, 메모, 잠금, 복제, 삭제를 조정합니다.
8. 확대/축소와 스크롤 팬은 화면 보기만 바꾸며 `xMm`, `yMm`, `widthMm`, `depthMm` 값을 바꾸지 않습니다.
9. LocalStorage 자동 저장을 사용하되 중요한 작업은 JSON 내보내기로 백업합니다.

## 실측 단위

내부 기준 단위는 mm입니다. 기존 파일 호환을 위해 cm 필드도 저장되지만, 새 구조에서는 mm 필드가 우선입니다.

## 현재 저장 방식

현재 `v0.1.0-alpha`는 LocalStorage 자동 저장과 JSON 파일 내보내기/가져오기를 중심으로 동작합니다.

## 현재 한계

- 도면 구조를 완전히 자동 인식하지 않습니다.
- 사용자가 도면 기준 영역과 실측 크기를 확인해야 합니다.
- 벽, 문, 창문 자동 벡터화는 포함하지 않습니다.
