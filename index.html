Features

알파 버전에서 바로 확인할 수 있는 기능

01

도면 기준 영역 보정

도면 이미지 전체가 아니라 실제 배치에 사용할 기준 영역을 맞춰 실측 워크스페이스와 연결합니다.

02

실측 그리드와 단위 관리

내부 데이터는 mm 기준으로 정리하고, 사용자는 가구 크기와 배치 위치를 실측 단위로 검토합니다.

03

가구 보관함과 배치 편집

프리셋 또는 직접 입력한 가구를 관리하고, 도면 위에서 위치, 크기, 회전을 조정합니다.

04

로컬 저장과 파일 백업

현재 버전은 브라우저 임시 저장과 JSON 내보내기/가져오기를 중심으로 알파 테스트할 수 있습니다.

Structure

개념은 단순하게 유지합니다

Layoutstudio는 사용자가 이해하기 쉽도록 저장 단위를 워크스페이스로 통합하고 그 안에서 도면과 가구를 관리합니다.

Workspace집, 방, 사무실 같은 하나의 저장 단위
Floorplan워크스페이스 안에 들어가는 도면 또는 방별 도면
Furniture Library배치 전 가구 원본과 프리셋 보관함
Placed Furniture도면 위에 실제로 배치된 가구 객체

How to Use

이용 방법

Step 1

워크스페이스 생성

도면 이미지를 첨부하고, 실제 크기와 기준 영역을 맞춥니다.

Step 2

가구 보관함 구성

기본 프리셋을 선택하거나 직접 가구 크기를 입력해 보관함을 만듭니다.

Step 3

마음껏 배치

가구를 도면 위로 꺼내 배치하고, 위치와 회전을 자유롭게 조정합니다.

Step 4

저장과 백업

작업 결과는 로컬에 저장하고, 중요한 작업은 JSON 파일로 백업합니다.

공간 둘러보기

휴대폰으로 방을 스캔하고 실제 공간 치수를 보정해 도면 구성의 출발점으로 활용하는 흐름을 검토합니다.
